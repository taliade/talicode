## Cómo usar
1. Abrí la carpeta en VS Code
2. Instalá la extensión **Live Server** para previsualizar
3. Para subir a Vercel: seguí los pasos del README

## Pendiente configurar
- Reemplazá el bloque placeholder en `contacto.html` con tu iframe de Go High Level
- Actualizá los links de WhatsApp, Instagram y TikTok en `contacto.html`
- Agregá tu número de WhatsApp real
